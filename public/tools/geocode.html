Batch geocoder

Turns the extractor's coordinate-less rows into plottable ones. Load the batch JSON, geocode it, eyeball every result, then download the patched file and run it back through scripts/ingest-kijobs.mjs.

Uses OpenStreetMap's Nominatim. Free, and its licence permits storing the results permanently — which matters, because these coordinates go into projects.json and stay there. Mapbox and Google both restrict permanent storage of geocoding results under their standard terms, so neither is used here despite being faster. Nominatim asks for one request per second, so 62 rows takes about a minute. Please don't hammer it.
